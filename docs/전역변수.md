# 전역변수 (ASIS)
## 개요
- frontend에서는 로그인 시 전역변수를 설정합니다.
- 전역변수의 종류는 gdsUserInfo, gdsCommCode, gdsMenu, gdsCentStndVl, gdsCentList, gdsTeamList, gdsUserList, gdsMsgList 입니다.
- 각 전역변수는 TOBE에서 사용여부에 따라 삭제하거나 변수명을 변경합니다.
- 본 문서는 변경된 내용에 대하여 기재합니다.

| 데이터세트 | 사용구분 |
|---|---|
| gdsUserInfo | 일부사용 |
| gdsCommCode | 일부사용 |
| gdsMenu | 일부사용 |
| gdsCentStndVl | 사용안함 |
| gdsCentList | 사용안함 |
| gdsTeamList | 사용안함 |
| gdsUserList | 사용안함 |
| gdsMsgList | 사용안함 |

## 전역변수 매핑
### gdsUserInfo
* 매핑 정보
    | 컬럼 | 컬럼명 | 대응 컬럼 | 설명 | 상태 |
    |---|---|---|---|---|
    | USR_CD | 사용자id | user_id | 사용자id | |
    | CENT_CD | 센터코드 | | setOrgComboValue, getTeamList, getCentList 등 스크립트 변경<br>조직코드로 사용자정보를 사용 | 삭제 |
    | CENT_NM | 센터이름 | | | 삭제 |
    | TEAM_CD | 팀코드 | | | 삭제 |
    | TEAM_NM | 팀이름 | | | 삭제 |
    | AUTH_LV | 권한레벨 | orgnz_lnq_rang_cd | 권한레벨을 이용하여 권한레벨을 추출하고 레벨을 사용<br>-> 권한테이블 조회/업데이트 코드 | |
    | USR_NM | 사용자명 | user_nm | | |
    | CONN_IP | 로그인ip | lgn_ip | CTI 로그인이 필요여부 확인<br>client 사용자 로그인 상태값 (10기본값) | |
    | PS_STA_CD | 로그인 상태 코드 | | - 로그인 실패 ""<br>- 로그인 성공 "10"<br>- 로그아웃 "20" | 삭제 |
    | LOGIN_DT | 로그인일자 | | 사용안함 | 삭제 |
    | ACT_STA_CD | 활동상태 | | STT플레어시 필요 | 삭제 |
    | USE_YN | 사용여부 | use_yn | | 삭제 |
    | TEAM_TP_CD | 팀유형코드 | | 팀유형코드 (TBL_SYS_TEAM_INFP_TP_CD)<br>팀유형에 따라 조직코드의 기본값 설정 QA 등<br><br>common/index.js setOrgComboValue 수정 필요 | 삭제 |


* 쿼리문
    ```sql
    SELECT
        A.USR_CD
        , A.CENT_CD
        , SFTM_GET_CENT_NAME(A.CENT_CD) AS CENT_NM
        , A.TEAM_CD
        , SFTM_GET_TEAM_NAME(A.CENT_CD, A.TEAM_CD) AS TEAM_NM
        , A.AUTH_LV
        , A.USR_NM
        , B.CONN_IP
        , '10' AS PS_STA_CD
        , DATE_FORMAT(CURRENT_DATE(), '%Y%m%d') AS LOGIN_DT
        , A.ACT_STA_CD
        , A.USE_YN
        , (SELECT TP_CD FROM TBL_SYS_TEAM_INF WHERE TEAM_CD = A.TEAM_CD) AS TEAM_TP_CD
    FROM STT_TBL_USR A		
    LEFT OUTER JOIN TBL_SYS_LGN B
    ON (A.USR_CD = B.USR_CD)
    WHERE A.USR_CD = #{USR_CD}
    ```
* 변수명
    ```javascript
    USR_CD
    CENT_CD
    CENT_NM
    TEAM_CD
    TEAM_NM
    AUTH_LV
    USR_NM
    CONN_IP
    PS_STA_CD
    LOGIN_DT
    ACT_STA_CD
    USE_YN
    TEAM_TP_CD
    ```


## gdsCommCode
* 매핑 정보
    | 컬럼 | 컬럼명 | 대응 컬럼 | 설명 | 상태 |
    |---|---|---|---|---|
    | BIG_CD | 대분류 코드 | cd_group | 공통코드 로그인 시 조회한 후 사용<br>common/index.js getCommCodeList 수정 필요 | |
    | MDL_CD | 중분류 코드 | | 사용 안함 | 삭제 |
    | CODE | 코드 | cd | common/index.js<br>getComCodeValue<br>getComCodeName<br>getComCodeCdVal<br>convComboList<br><br>components/Tree/index.js | |
    | CODE_NM | 코드 명 | cd_nm | | |

* 쿼리문
    ```sql
    SELECT
        B.BIG_CD
        , B.MDL_CD
        , B.SML_CD AS CODE
        , B.SML_NM AS CODE_NM
    FROM STT_TBL_CMN_CD_BIG A
    INNER JOIN STT_TBL_CMN_CD_SML B
    ON (A.BIG_CD = B.BIG_CD AND A.MDL_CD = B.MDL_CD)
    WHERE A.USE_YN = 'Y'
    AND B.USE_YN = 'Y'
    ORDER BY A.BIG_CD, B.SORT_NO
    ```
* 변수명
    ```javascript
    BIG_CD
    MDL_CD
    CODE
    CODE_NM
    ```

    | 컬럼 | 컬럼명 | 대응 컬럼 | 설명 | 상태 |
    |---|---|---|---|---|
    | MNU_ID | 메뉴 id | menu_id | | |
    | MNU_NM | 메뉴 이름 | menu_nm | 모두 찾기 후 변경 | |
    | PARE_MNU_ID | 상위 메뉴 id | up_menu_id | | |
    | SORT_ORD | 정렬 순번 | sort_sn | | |
    | USE_YN | 사용 여부 | | | 삭제 |
    | PGM_PATH | 화면 경로 | url_addr | | |
    | MNU_KND | 메뉴 종류 | | 메뉴 유형 (10, 20 -> 실행 프로그램)<br>-> 특별하게 사용되는 곳 없음 | 삭제 |

* 쿼리문
    ```sql
    SELECT
        A.MNU_ID
        , A.MNU_NM
        , A.PARE_MNU_ID
        , A.SORT_ORD
        , A.USE_YN
        , A.PGM_PATH
        , A.MNU_KND
    FROM TBL_SYS_MNU_INF A
    INNER JOIN TBL_SYS_MNU_AUTH B
    ON (A.MNU_ID = B.MNU_ID AND B.AUTH_LV = #{AUTH_LV})
    WHERE A.USE_YN = 'Y'
    ORDER BY A.SORT_ORD
    ```
* 변수명
    ```javascript
    MNU_ID
    MNU_NM
    PARE_MNU_ID
    SORT_ORD
    USE_YN
    PGM_PATH
    MNU_KND
    ```
## gdsCentStndVl
* 사용안함
* 쿼리문
    ```sql
    SELECT
        B.CENT_CD
        , A.STND_CD
        , A.STND_CD_NM
        , B.APY_YN
        , B.STND_VL
        , B.ETC1_CONT
        , B.ETC2_CONT

    ON (A.STND_CD = B.STND_CD AND B.CENT_CD = #{CENT_CD})
    ```
