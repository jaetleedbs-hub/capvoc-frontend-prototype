## 4. 기능 정의

| 트랜잭션 ID | 기능 | 계기 | 검증 | API | API 상태 | 요청 | 응답 | 후처리 |
|---|---|---|---|---|---|---|---|---|
| `SMP0010R01` | 목록 조회 | 화면 열림 · [조회] · 엔터 | — | `POST /api/smp/sample/r01` | 미구현 | `smplNm`, `useYn` | `[{ smplId, smplNm, useYn, rmrkCn }]` | 목록 채움 · 상세 비움 |
| `SMP0010U01` | 저장 | [저장] → 확인창 | 샘플명 필수 | `POST /api/smp/sample/u01` | 미구현 | `rowtype`(c/u) + 상세 칸 | — | 「저장되었습니다.」 → 다시 조회 |
| `SMP0010D01` | 삭제 | [삭제] → 확인창 | 행 선택 | `POST /api/smp/sample/d01` | 미구현 | `smplId` | — | 「삭제되었습니다.」 → 다시 조회 |

- API 상태: `구현`(백엔드에 있다 — 컨트롤러 경로를 적는다) · `미구현`(계획값).
- 화면 안에서만 일어나는 일(행 클릭 → 상세 채움, [신규] → 상세 비움)도 적는다:

| 계기 | 일 |
|---|---|
| 목록 행 클릭 | 상세에 그 행을 채운다 |
| [신규] | 상세를 비우고 목록 선택을 푼다 |
| [↺] | 검색 칸을 처음 값으로 |
