# 컴포넌트 정리

출처는 `src/components` 다. 화면에서는 폴더를 직접 가져오지 않고 배럴만 쓴다.

```js
import { FullPanel, SearchPanel, Label, Textfield, BasicButton, Grid } from 'components';
```

대부분 class 컴포넌트다. 보이는 글자는 `value` 나 `dataset` 의 `name` 에 넣고, 화면 문구는 `TEXT` 상수로 둔다. 새 CSS 파일은 만들지 않는다. 색이 필요하면 `var(--cw-*)` 만 쓴다.

배럴에 없는 파일은 화면에서 쓰지 않는다. 맨 아래 「배럴에 없는 것」을 본다.

---

## 1. 한눈에 보기

| 쓰는 곳 | 이름 |
| --- | --- |
| 화면 뼈대 | `FullPanel`, `SubFullPanel`, `SearchPanel`, `ComponentPanel`, `FlexPanel`, `LFloatArea`, `RFloatArea`, `RelativeGroup` |
| 글자·입력 | `Label`, `Textfield`, `Textarea`, `TextPasswdfield`, `NumberStepper` |
| 날짜 | `InputCalendar`, `RangeInputCalendar` |
| 선택 | `Selectbox`, `ComboList`, `Checkbox`, `Radio`, `MultiCheckBox`, `MulitSelectBox`, `Switch`, `ToggleButtonGroup` |
| 찾기 | `OgnzSelect`, `UserSelect`, `UserMultiSelect` |
| 버튼 | `BasicButton`, `IconButton` |
| 목록 | `Grid`, `Table` |
| 묶음 | `Tabs`, `TabPanel`, `Tree`, `SortableTree`, `TagSelector` |
| 안내 | `Dialog`(객체), `ErrorBoundary`, `ProgressBar` |
| 파일·글·그림 | `InputFileUpload`, `HtmlEditor`, `CustomSlide`, `ScrmBarChart`, `ScrmLineBarChart`, `ScrmRadialBarChart` |
| 셸 전용 | `AppPanel`, `HeadPanel`, `MiddlePanel`, `SidePanel`, `MainPanel`, `FooterPanel`, `TrayPanel`, `TrayDiv`, `Menu`, `HeaderMenu`, `DashboardPanel`, `BottomPanel` |

업무 화면의 기본 골격은 `FullPanel` → `SearchPanel`(조건) → `SubFullPanel` + `ComponentPanel`(결과) 이다.

## 2. 화면 뼈대

모두 `children` 을 감싸는 div 다. `className` 을 덧붙일 수 있다.

| 이름 | 쓰는 때 | 크기 |
| --- | --- | --- |
| `FullPanel` | 화면 맨 바깥 | `width` |
| `SubFullPanel` | 검색 아래 본문. 높이를 채운다 | `width`, `height` |
| `SearchPanel` | 조회 조건 한 줄 | — |
| `ComponentPanel` | 카드 한 칸. `sizeVar` 가 참이면 높이 가변 클래스 | `width`, `height` |
| `FlexPanel` | 가로로 나란히 | `style` |
| `LFloatArea` / `RFloatArea` | 왼쪽·오른쪽 붙이기 | `style` |
| `RelativeGroup` | 상대 배치 묶음 | `width`, `style` |
| `BottomPanel` | 하단 버튼 줄 | `style` |
| `DashboardPanel` | 대시보드 칸 | `width` |

```jsx
<FullPanel>
  <SearchPanel>
    <FlexPanel>
      <Label value="이름" />
      <Textfield id="iptNm" value={this.state.iptNm} onChange={this.onChange} />
      <BasicButton value="조회" color="blue" filled onClick={this.onSearch} />
    </FlexPanel>
  </SearchPanel>
  <SubFullPanel>
    <ComponentPanel>
      <Grid id="grdList" areaName="목록" header={this.header} data={this.state.dsList} height="400px" />
    </ComponentPanel>
  </SubFullPanel>
</FullPanel>
```

`AppPanel`, `HeadPanel`, `MiddlePanel`, `SidePanel`, `MainPanel`, `FooterPanel`, `TrayPanel` 은 로그인 이후 셸이 쓴다. 업무 화면 안에 다시 넣지 않는다.

## 3. 글자와 입력

### Label

조회 조건 이름. `value` 가 글자다. `req` 가 참이면 필수 표시 클래스가 붙는다. `content` 가 참이면 글자색이 회색이다.

```jsx
<Label value="조직" req />
```

### Textfield

한 줄 입력. `value` 와 `onChange(event)` 가 기본이다. `event.target.value` 를 state 에 넣는다.

| 속성 | 뜻 |
| --- | --- |
| `id`, `name` | 식별자 |
| `value` | 현재 값. 비면 빈 문자열 |
| `placeholder`, `maxLength`, `minLength` | 안내와 길이 |
| `readOnly`, `disabled` | 읽기 전용, 비활성 |
| `width`, `style`, `textStyle` | 칸 크기와 글자 스타일 |
| `type` | `onlyNum` 숫자만, `onlyKor` 한글만, `onlyEng` 영문만. 없으면 그대로 |
| `onKeyDown`, `onKeyPress`, `onBlur`, `onFocus`, `onClick` | 키와 포커스 |

### Textarea

여러 줄. `rows` 기본 3. `type` 은 Textfield 와 같다. `onChange(event)` 로 받는다.

### TextPasswdfield

비밀번호. `type="password"`. 길이 속성 이름은 `maxlength`, `minlength` 다(소문자).

### NumberStepper

숫자 증감. `value`, `min`(0), `max`(999999), `step`(1), `width`. `onChange` 는 `{ target: { id, value } }` 를 준다. `disabled` 나 `readOnly` 이면 값이 안 바뀐다.

```jsx
<NumberStepper id="iptCnt" value={this.state.cnt} min={1} max={100} step={1} onChange={this.onCount} />
```

## 4. 날짜

### InputCalendar

날짜 하나. 값은 `YYYYMMDD`(월 달력이면 `YYYYMM`) 문자열이다. 화면에는 `YYYY-MM-DD` 로 보인다.

| 속성 | 뜻 |
| --- | --- |
| `value` | `YYYYMMDD` |
| `onChange` | `{ target: { id, value } }`. value 는 숫자만 남긴 문자열 |
| `disabled` | 비활성 |
| `placeholder` | 기본 `일자를 선택하세요` |
| `inputWidth` | 기본 `120px` |
| `direction` | 달력 위치. 기본 `auto` |
| `plugins` | `'month'` 이면 월만 고른다 |

### RangeInputCalendar

시작·끝. `startDate`, `endDate` 는 `YYYYMMDD`. `onChange` 로 두 값이 같이 온다. `useClearButton` 이 참이면 지우기 버튼이 있다. 월 달력은 쓰지 않는다.

## 5. 선택

### Selectbox

한 값 선택. `dataset` 은 `{ value, name }` 배열이다. `value` 가 선택된 값이다.

```jsx
<Selectbox
  id="selUseYn"
  value={this.state.useYn}
  width="120px"
  dataset={[{ value: '', name: '전체' }, { value: 'Y', name: '사용' }, { value: 'N', name: '미사용' }]}
  onChange={(e) => this.setState({ useYn: e.target.value })}
/>
```

`readOnly` 이면 목록이 안 열린다. `disabled` 이면 비활성이다. `color` 가 있으면 `scrm-react-custom-selectbox-{color}` 클래스가 붙는다.

공통코드는 `ComLib.convComboList(ComLib.getCommCodeList('그룹코드'), '전체')` 로 `dataset` 을 만든다.

`CentListSelectBox`, `TeamListSelectBox`, `UsrListSelectBox` 는 예전 센터·팀·사용자 콤보다. 소스에 `@Deprecated` 가 있다. 새 화면은 `OgnzSelect`, `UserSelect` 를 쓴다.

### ComboList

검색이 되는 선택 목록. `dataset` 은 `{ value, name, sub? }` 다. `value` 가 선택값이고, `onChange` 는 Selectbox 와 같이 `{ target, id }` 다. `placeholder` 기본은 `선택`, 검색칸 기본은 `검색...`.

### Checkbox

`checked` 는 불리언이 아니다. `'Y'` 일 때만 체크된다.

| 속성 | 뜻 |
| --- | --- |
| `id`, `index`, `keyProp` | DOM id 를 이 셋으로 만든다. `keyProp` 에 공백이 있으면 id 가 깨진다 |
| `value` | 라벨 글자 |
| `checked` | `'Y'` 또는 그 외 |
| `onChange`, `onClick` | `{ id, index, checked, target }` |

### MultiCheckBox

`dataset` 을 Checkbox 여러 개로 그린다. 각 항목의 체크는 `item.value === 'Y'` 다. 보이는 글자 키는 `value` prop, 값 키는 `keyProp` prop 이다.

### MulitSelectBox

이름 철자가 `Multi` 가 아니다. 여러 값을 드롭다운으로 고른다. `dataset` 항목의 `value` 가 `'Y'` 이면 선택된 것이다. 보이는 글자 키는 `value` prop 이다. 전부 선택되면 글자가 `전체선택` 이다.

### Radio

`dataset` 배열, 값 키 `keyProp`, 글자 키 `value`. 선택값은 `selected`. `onChange` 는 `{ id, value }` 다. `defaultSelected` 는 인덱스로, `selected` 가 없을 때 쓴다.

### Switch

켜기/끄기. `checked` 는 불리언이다. `onChange` 는 이 컴포넌트에 묶여 호출되므로, 넘기는 함수가 컴포넌트 메서드여야 한다.

### ToggleButtonGroup

버튼이 붙은 단일 선택. `dataset` 은 `{ value, name }`. `value` 가 현재 값이다. `onChange` 는 Selectbox 와 같은 `{ target, id }` 다. `disabled`, `readOnly` 이면 안 바뀐다.

## 6. 조직·사용자 찾기

로그인 사용자의 조회 범위(`ognzInqRangCd`)를 탄다. `authrt` 가 참(기본)이면 권한에 맞게 값을 채운다.

| 이름 | 값 | 고르기 |
| --- | --- | --- |
| `OgnzSelect` | `ognzCd`, `ognzNm`, `keyword` | 조직 하나. `isMultiSelect` 가 참이면 여러 조직 |
| `UserSelect` | `userId`, `userNm`, `keyword` | 사용자 하나 |
| `UserMultiSelect` | `selectedUsers` 배열 | 여러 사용자. `maxUsers`, `maxVisibleTags`(기본 4) |

공통으로 `id`, `title`, `placeholder`, `disabled`, `readOnly`, `onChange`, `onKeywordChange`, `onReady` 가 있다. `onReady` 는 권한 처리가 끝난 뒤 호출된다.

## 7. 버튼

### BasicButton

```jsx
<BasicButton value="저장" color="blue" filled onClick={this.onSave} disabled={this.state.saving} />
<BasicButton value="삭제" color="red" onClick={this.onDelete} />
```

| 속성 | 뜻 |
| --- | --- |
| `value` | 버튼 글자 |
| `color` | `blue`, `grey`, `red` 등. 기본 `grey` |
| `filled` | 참이면 채운 버튼, 거짓이면 테두리만. 예전 오타 `fiiled` 도 참이면 채운다 |
| `size` | 기본 `md` |
| `disabled` | 비활성 |
| `mt`, `mr`, `mb`, `ml` | 바깥 여백. 기본 `0px` |
| `innerImage` + `icon` | 글자 없이 아이콘. `save`, `add`, `del`, `check`, `trash`, `srch`, `download`, `left`, `right`, `close` 등 |
| `onClick` | 클릭. 누른 뒤 포커스를 뺀다 |

주 동작은 `color="blue" filled`, 나머지는 테두리 버튼이다.

### IconButton

`classes` 로 클래스만 거는 빈 버튼이다. `id`, `style`, `tooltip`, `onClick`. 글자 버튼은 `BasicButton` 을 쓴다.

## 8. 표

### Table

라벨·값 표. 데이터가 많은 목록은 `Grid` 를 쓴다.

```jsx
<Table
  id="tblDetail"
  colGrp={[{ width: '120px' }, { width: '*' }]}
  tbData={[
    [{ type: 'T', value: '코드', required: true }, { type: 'D', value: this.state.cd }],
    [{ type: 'T', value: '이름' }, { type: 'D', value: <Textfield id="iptNm" value={this.state.nm} onChange={this.onChange} /> }],
  ]}
/>
```

`tbData` 는 행 배열이고, 칸은 `{ type, value, colSpan, rowSpan, className, required }` 다. `type: 'T'` 는 머리 칸(`th`), 그 외는 값 칸(`td`)이다. `value` 에는 글자나 다른 컴포넌트를 넣는다.

### Grid

ag-grid 목록. `data` 는 `DataLib.datalist` 인스턴스다. 배열을 그대로 넣지 않는다.

```jsx
this.header = [
  { headerName: '코드', field: 'cd', colId: 'cd', width: 120, textAlign: 'center' },
  { headerName: '이름', field: 'nm', colId: 'nm', width: 240, editable: true, req: true },
];

<Grid
  id="grdList"
  areaName="목록"
  header={this.header}
  data={this.state.dsList}
  height="400px"
  rowSelection="single"
  onRowClicked={this.onRowClicked}
/>
```

| 속성 | 기본 | 뜻 |
| --- | --- | --- |
| `header` | `[]` | 열 정의 |
| `data` | `[]` | `DataLib.datalist` |
| `height` | — | 그리드 높이 |
| `rowSelection` | `single` | `single` 또는 `multiple` |
| `sort` | `true` | 열 정렬 |
| `filter` | `false` | 필터 |
| `addRowBtn`, `delRowBtn`, `dnlExcelBtn` | `false` | 행 추가, 삭제, 엑셀 |
| `infinite` | — | 스크롤 끝에 `onScrollEnd` |
| `rowNum` | — | 행 번호 열 |
| `tree` | — | 트리 그리드. `treeHeaderMap` 으로 키 이름을 바꾼다 |

열에서 자주 쓰는 키는 `headerName`, `field`, `colId`, `width`, `textAlign`, `editable`, `req`, `hide` 다. `type` 이 `date`, `number`, `phone`, `email` 등이면 표시 형식이 붙는다. `req: true` 이면 머리글에 `*` 가 붙는다.

이벤트는 `onGridReady`, `onRowClicked`, `onRowDoubleClicked`, `onCellClicked`, `onCellValueChanged`, `onSelectionChanged`, `onScrollEnd`, `onDeleteRow` 다. 행을 넣기 전에 `onBeforeInsertRow` 가 `{ rtn: false }` 를 반환하면 추가하지 않는다.

## 9. 탭·트리·태그

### Tabs, TabPanel

`Tabs` 의 자식은 `TabPanel` 이다. `index` 로 구분하고 `label` 이 탭 글자다. `display="none"` 인 탭은 숨긴다. `onClick` 은 선택된 index 를 받는다.

```jsx
<Tabs id="tabMain" height="400px" onClick={(index) => this.setState({ tab: index })}>
  <TabPanel index={0} label="기본"><ComponentPanel>...</ComponentPanel></TabPanel>
  <TabPanel index={1} label="상세"><ComponentPanel>...</ComponentPanel></TabPanel>
</Tabs>
```

`Tab` 은 `Tabs` 가 안에서 만든다. 배럴로 나가지 않는다.

### Tree

계층 목록. 평면 배열을 넘긴다. 기본 필드 이름은 `ID`, `PARENT_ID`, `TITLE`, `SORT_ORD` 이고 `idField`, `parentField`, `titleField`, `sortField` 로 바꾼다.

`openAllonInitial` 이 참이면 처음부터 편다. `maxDepth` 기본 10. `onNodeClick`, `onNodeDoubleClick`, `onRowSelect`, `onChange`.

### SortableTree

순서를 끄는 트리. `Tree` 와 같은 필드 이름을 쓴다. `addRowBtn`, `delRowBtn`, `ediRowBtn`, `allowSearch`, `allowDel`. `onMoveNode`, `onRowDelete`, `onChange`.

### TagSelector

태그 버튼. `tags` 는 `{ name, color }` 배열. `color` 는 `red`, `blue`, `green` 같은 이름이다. `selectedTags`, `onTagClick`. 한 줄에 `maxTagsPerLine`(기본 4), 최대 `maxLines`(기본 2).

## 10. 대화상자와 오류

알림·확인은 컴포넌트를 직접 두기보다 `ComLib` 를 쓴다.

```js
ComLib.openDialog('A', '', '저장했습니다.');
ComLib.openConfirmDialog('삭제하시겠습니까?', (ok) => { if (ok) this.remove(); });
```

`Dialog` 기본 export 는 컴포넌트가 아니라 객체다.

| 키 | 쓰는 때 |
| --- | --- |
| `AlertDialog` | `open`, `message`, `onClose`. 확인 하나 |
| `ConfirmDialog` | 예/아니오. `onClose` 에 선택이 간다 |
| `ModalLoading` | 처리 중 표시. 건수를 넣으면 스피너 가운데에 보인다 |
| `PopupDialog` | Redux `popupList` 에 연결된 팝업 창 |

### ErrorBoundary

자식 렌더가 깨지면 화면 대신 다시 시도 UI 를 보여 준다. `showUserMessage` 가 거짓이 아니면 상태 메시지를 띄운다.

### ProgressBar

`data` 는 0~100 숫자. `options.type`, `options.status`(`default`, `error`, `success`)를 넘긴다.

## 11. 파일·본문·차트·슬라이드

### InputFileUpload

파일 올리기. `height` 기본 200. `uploadValidation` 이 거짓을 반환하면 올리지 않는다. `onUploadComplete({ id, msg, files, savedFileList })`, `onChangeStatus`.

`MultiFileUpload`, `IconFileUpload` 는 빈 컴포넌트다. 화면에 아무것도 그리지 않는다.

### HtmlEditor

서식 있는 본문. `value` 는 HTML 이고, 그리기 전에 허용된 태그만 남긴다. `onChange({ id, value })`. `height` 는 편집 영역 높이(px). `toolbarHidden`, `readOnly`.

### CustomSlide

이미지 슬라이드. `data` 는 `{ FILE_NM }` 배열. `height` 기본 200. 이미지 주소는 `API_URL + 'img/' + FILE_NM` 이다.

### 차트

`recharts` 를 감싼다.

| 이름 | 데이터 |
| --- | --- |
| `ScrmBarChart` | `data`, `width`, `height`, `layout`, `dailyOptions.YAsisKey`, `dailyOptions.dataKey`(`{ key, color }` 배열). 값 축은 0~100 |
| `ScrmLineBarChart` | 범례를 눌러 선을 끄고 켠다 |
| `ScrmRadialBarChart` | 현재 소스의 고정 예시 데이터를 그린다. 화면 데이터를 받지 않는다 |

## 12. 셸이 쓰는 것

업무 화면에서 새로 만들지 않는다.

| 이름 | 하는 일 |
| --- | --- |
| `Menu` | 좌측 메뉴. `menu` 배열(`menuId`, `menuNm`, `upMenuId`) |
| `HeaderMenu` | 상단 1단 메뉴. 같은 `menu` 배열. 빈 `upMenuId` 만 1단에 나온다 |
| `TrayDiv` | 열린 화면 탭. `data`, `selected`, `onSelect`, `onClose` |

## 13. 배럴에 없는 것

폴더는 있어도 `src/components/index.js` 에서 나가지 않는다. 화면의 import 에 넣지 않는다.

| 위치 | 상태 |
| --- | --- |
| `ApiErrorBanner` | `{ error, onRetry }`. `error` 는 `{ cause, action, raw }`. 탭 안의 조회 실패 배너 |
| `Button` 의 `BadgeButton` | 클래스만 있는 빈 버튼. 배럴 미포함 |
| `Badge` | 파일이 비어 있다 |
| `Grid/components` | 셀 안의 날짜·체크·버튼·선택. Grid 가 내부에서 쓴다 |
| `FileManager` | 업로드 보조. 배럴 미포함 |
